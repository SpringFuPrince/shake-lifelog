# 长期跟踪与周期对比

## 选一个每次都能重算的口径

1. 从用户想了解的变化确定指标和基线。已有明确目标或上次口径时沿用。没有时，优先选从现有记录可稳定提取的指标。回顾习惯可从最近几个完整自然周开始，频率低时按月。当前周未结束时，用截至同一星期几的窗口比较，或将本周至今单独显示。
2. 用相同类别、分组规则、单位、去重方式、分母和缺值处理重算比较窗口。用记录 ID 去除重复读取，再按类别合并证据明确的同一事件。把晚到、修订或删除影响到的周期重查。检查当前 Mac 的数据和照片覆盖，尤其是两段覆盖明显不同时。
3. 表达绝对值与变化，附有效样本和影响解读的限制。记录很少或集中在少数天时，按具体实例描述。增长百分比需要可比且非零的基线。没有记录、未能读取和指标已知为零用不同状态表示。可视化时标注缺测，保留采样不均匀的真实日期。

| 用户关心的事 | 可复用指标 | 对比时一起看 |
| --- | --- | --- |
| 饮食搭配是否变化 | 有照片或备注可判断的餐次中，出现目标食物的餐次数 | 可判断餐次和覆盖的日期 |
| 体重最近往哪走 | 确认称量的周均值或周中位数 | 有效称量日数、称量条件、较长区间的波动 |
| 哪些情况下情绪容易变化 | 自述明确的情绪、重复情境及有记录的缓解方式 | 明确自述的记录数、空白日期、实际时间先后 |
| 学习有什么积累 | 去重后的主题、值得回看的素材、已记下的复习或应用 | 新主题与旧主题的联系、出处和图片可读性 |
| 运动是否更规律 | 每周运动日及活动次数，按类型汇总已知时长 | 有时长的活动数、连续覆盖的周数 |

## 跨类回顾

围绕用户的问题挑相关类别，把记录按当地日期和发生时间对齐。比较发生过的实例和有共同记录覆盖的日子。一次同现用来描述某天发生了什么。重复同现时报告几次、在哪些日子和有哪些例外。用户明确写下「散步后感觉缓和」时，可复述这段体验。饮食照片、运动或日历空白无法单独解释体重和心情变化。

可以把多类结果组织成短表，例如「变化」「依据」「下次继续看」，也可以先给整体变化，再列出最有代表性的几天。表格和图只承载可比较的信息，方向尚不明确时保留原值和记录覆盖。

## 下次接着看

延续跟踪时，在用户可复用的摘要中保留目标、指标口径、基线日期与数值、最近已分析周期、有效样本及代表记录。下次用拾刻重新查相应区间，有晚到或修订时更新基线与后续结果。工具只读。用户要求保存时使用其指定且可用的位置，用户明确要求定期报告时才走客户端的定期任务功能。当前对话内可以持续比较手头记录，定期交付依赖实际建立的任务。
